# How to Cite a PDF in APA, MLA & Chicago Format (2026 Guide)

You found the perfect source for your research paper — but it's a PDF. Now what? How do you cite it without losing points?

Here's the thing: **you don't cite the PDF format itself.** You cite the original source that happens to be in PDF format. But there are specific rules to follow depending on what type of document the PDF contains.

In this guide, you'll learn exactly how to cite PDFs in APA, MLA, and Chicago formats — with examples you can copy for every common scenario.

## The Golden Rule of PDF Citations

**Cite the source, not the format.**

A PDF is just a file format — like .docx or .jpg. What matters for your citation is what's inside the PDF:

- Is it a journal article? Cite it as a journal article.
- Is it a book chapter? Cite it as a book chapter.
- Is it a government report? Cite it as a government report.
- Is it a webpage saved as PDF? Cite it as a webpage.

The only time PDF format matters is when you need to indicate that you retrieved a document in PDF form (which some style guides require for certain sources).

## How to Cite a PDF in APA Format (7th Edition)

APA doesn't require you to specify that a document was in PDF format. Focus on the original source type.

### PDF from a Website (Report or Document)

**Reference List Format:**
```
Author, A. A. (Year). Title of document. Site Name. URL
```

**Example:**
```
World Health Organization. (2024). Global health statistics 2024. WHO. https://www.who.int/data/gho/publications/global-health-statistics-2024.pdf
```

**In-Text Citation:**
```
(World Health Organization, 2024)
```

### PDF of a Journal Article

**Reference List Format:**
```
Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), Page–Page. https://doi.org/xxxxx
```

**Example:**
```
Smith, J. K., & Johnson, L. M. (2025). The impact of remote learning on student outcomes. Journal of Educational Psychology, 117(3), 234–251. https://doi.org/10.1037/edu0000789
```

**In-Text Citation:**
```
(Smith & Johnson, 2025)
```

### PDF Ebook

**Reference List Format:**
```
Author, A. A. (Year). Title of book. Publisher. URL
```

**Example:**
```
Brown, R. T. (2023). Understanding cognitive development. Academic Press. https://example.com/cognitive-development.pdf
```

**In-Text Citation:**
```
(Brown, 2023, p. 45)
```

### Pro Tip for APA

If the PDF has no page numbers (common with online PDFs), use paragraph numbers or section headings in your in-text citations:

```
(Smith, 2024, para. 12)
(Smith, 2024, "Methods" section)
```

## How to Cite a PDF in MLA Format (9th Edition)

MLA focuses on the container (where you found the source) and may require noting the file format in some cases.

### PDF from a Website

**Works Cited Format:**
```
Author Last Name, First Name. "Title of Document." Website Name, Day Month Year, URL.
```

**Example:**
```
United Nations. "Sustainable Development Goals Report 2025." United Nations, 15 July 2025, https://unstats.un.org/sdgs/report/2025/SDG-Report-2025.pdf.
```

**In-Text Citation:**
```
(United Nations 12)
```

### PDF of a Journal Article

**Works Cited Format:**
```
Author Last Name, First Name. "Title of Article." Journal Name, vol. #, no. #, Year, pp. #–#. Database Name, URL.
```

**Example:**
```
Martinez, Elena. "Social Media's Effect on Academic Performance." Educational Research Quarterly, vol. 48, no. 2, 2025, pp. 89–112. JSTOR, https://www.jstor.org/stable/12345678.
```

**In-Text Citation:**
```
(Martinez 95)
```

### PDF Ebook

**Works Cited Format:**
```
Author Last Name, First Name. Title of Book. Publisher, Year. PDF file.
```

**Example:**
```
Williams, Sarah. Research Methods for Students. Oxford UP, 2024. PDF file.
```

**Note:** MLA 9th edition allows you to add "PDF file" at the end when the format is relevant to your discussion.

## How to Cite a PDF in Chicago Format

Chicago offers two systems: Notes-Bibliography (humanities) and Author-Date (sciences). Here's both.

### Notes-Bibliography Style

**Footnote/Endnote (First Reference):**
```
1. Author First Name Last Name, Title of Document (Place: Publisher, Year), Page, URL.
```

**Example:**
```
1. Federal Reserve Board, Monetary Policy Report (Washington, DC: Federal Reserve, 2025), 23, https://www.federalreserve.gov/monetarypolicy/files/2025-mpr.pdf.
```

**Bibliography Entry:**
```
Federal Reserve Board. Monetary Policy Report. Washington, DC: Federal Reserve, 2025. https://www.federalreserve.gov/monetarypolicy/files/2025-mpr.pdf.
```

### Author-Date Style

**Reference List Format:**
```
Author Last Name, First Name. Year. "Title of Document." Place: Publisher. URL.
```

**Example:**
```
Federal Reserve Board. 2025. "Monetary Policy Report." Washington, DC: Federal Reserve. https://www.federalreserve.gov/monetarypolicy/files/2025-mpr.pdf.
```

**In-Text Citation:**
```
(Federal Reserve Board 2025, 23)
```

## Citing Different Types of PDF Documents

Here's a quick reference for the most common PDF types you'll encounter:

### Government Reports (PDF)

**APA:**
```
U.S. Department of Education. (2025). National education technology plan. https://tech.ed.gov/files/2025/netp2025.pdf
```

**MLA:**
```
United States, Department of Education. National Education Technology Plan. 2025, https://tech.ed.gov/files/2025/netp2025.pdf.
```

### Academic Papers or Theses (PDF)

**APA:**
```
Chen, W. (2024). Machine learning applications in healthcare (Publication No. 28493021) [Doctoral dissertation, Stanford University]. ProQuest Dissertations and Theses Global.
```

**MLA:**
```
Chen, Wei. "Machine Learning Applications in Healthcare." 2024. Stanford University, PhD dissertation. ProQuest Dissertations and Theses Global.
```

### Conference Papers (PDF)

**APA:**
```
Roberts, M. K., & Lee, S. (2025). Innovations in renewable energy storage. In Proceedings of the International Energy Conference (pp. 156–167). IEEE. https://doi.org/10.1109/IEC.2025.12345
```

### Manuals or Technical Documents (PDF)

**APA:**
```
Microsoft Corporation. (2025). Azure cloud computing documentation (Version 3.0). https://docs.microsoft.com/azure/azure-documentation-v3.pdf
```

## Common PDF Citation Mistakes to Avoid

### ❌ Mistake 1: Citing "PDF" as the author

**Wrong:**
```
PDF. (2025). Research report.
```

**Right:** Find the actual author — individual, organization, or use the document title.

### ❌ Mistake 2: Using the file name as the title

**Wrong:**
```
report_final_v2.pdf
```

**Right:** Use the actual document title from the first page or header.

### ❌ Mistake 3: Linking to a temporary or personal download

**Wrong:**
```
file:///C:/Users/Student/Downloads/report.pdf
```

**Right:** Always use the original source URL where others can find the document.

### ❌ Mistake 4: Forgetting the retrieval date for unstable sources

If the PDF might change or be removed, include an access date (especially in Chicago and some MLA contexts):

```
Accessed May 3, 2026.
```

### ❌ Mistake 5: Not including page numbers

PDFs often have different page numbering. Use:
- PDF page numbers (what your reader displays)
- Document page numbers (printed on the page)
- Be consistent throughout your paper

## FAQ: PDF Citations

### Do I need to specify that a source is a PDF?

**Usually no.** Most style guides (APA 7, MLA 9, Chicago 17) don't require you to mention PDF format. The exception: if the format is relevant to your analysis (e.g., discussing digital accessibility).

### How do I cite a PDF with no author?

Use the organization name or document title:

**APA:** Centers for Disease Control and Prevention. (2025). *Health guidelines.*

**MLA:** "Health Guidelines." Centers for Disease Control and Prevention, 2025.

### How do I cite a PDF with no date?

**APA:** Use (n.d.) for "no date"
**MLA:** Omit the date or write "n.d."
**Chicago:** Write "n.d." where the date would appear

### How do I cite a scanned PDF of a print source?

Cite the original print source. Only add the database or URL if your professor requires it:

```
Johnson, M. (1998). Historical perspectives. University Press.
```

### Can I cite a PDF I found through Google?

Yes, but cite the original source, not Google. Find where the PDF actually comes from (the website that hosts it) and cite that.

## Key Takeaways

**Remember these rules for citing PDFs:**

- Cite the source type, not the file format
- Find the original author, title, and publication information
- Use the stable URL where the PDF is hosted
- Include page numbers when referencing specific content
- Match your citation style (APA, MLA, Chicago) requirements
