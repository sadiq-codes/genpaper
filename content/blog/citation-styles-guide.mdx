# APA vs MLA vs Chicago: Which Citation Style Should You Use?

One of the most confusing aspects of academic writing is choosing and correctly using citation styles. This guide breaks down the major citation formats and helps you pick the right one.

## Quick Reference: When to Use Each Style

| Style | Primary Fields | Key Characteristics |
|-------|---------------|---------------------|
| **APA** | Psychology, Education, Social Sciences | Author-date citations |
| **MLA** | Humanities, Literature, Arts | Author-page citations |
| **Chicago** | History, Business, Fine Arts | Footnotes or author-date |
| **IEEE** | Engineering, Computer Science | Numbered citations |
| **Harvard** | Business, Sciences (UK/Australia) | Author-date citations |

## APA Style (7th Edition)

The American Psychological Association style is the most common in social sciences.

### In-Text Citation Format
```
Research shows that climate change affects migration patterns (Smith, 2023).

Smith (2023) demonstrated that climate change affects migration patterns.
```

### Reference List Format
```
Smith, J. A. (2023). Climate change and human migration: A comprehensive analysis. 
    Journal of Environmental Studies, 45(3), 234-256. https://doi.org/10.1234/example
```

### Key Features
- Uses author-date format
- Emphasizes recency of sources (publication year prominent)
- DOIs required when available
- Running head on every page

### Best For
Psychology, education, nursing, social work, criminology, and other social sciences.

## MLA Style (9th Edition)

The Modern Language Association style dominates in humanities.

### In-Text Citation Format
```
Climate change significantly impacts migration (Smith 45).

Smith argues that "climate change is a primary driver of migration" (45).
```

### Works Cited Format
```
Smith, John A. "Climate Change and Human Migration: A Comprehensive Analysis." 
    Journal of Environmental Studies, vol. 45, no. 3, 2023, pp. 234-56.
```

### Key Features
- Uses author-page format
- Page numbers in citations (not year)
- Italicizes titles of longer works
- Container system for sources

### Best For
Literature, languages, cultural studies, philosophy, and other humanities.

## Chicago Style

Chicago offers two systems: Notes-Bibliography (humanities) and Author-Date (sciences).

### Notes-Bibliography System
```
Footnote:
1. John A. Smith, "Climate Change and Human Migration," Journal of 
Environmental Studies 45, no. 3 (2023): 245.

Bibliography:
Smith, John A. "Climate Change and Human Migration: A Comprehensive Analysis." 
    Journal of Environmental Studies 45, no. 3 (2023): 234-256.
```

### Author-Date System
```
In-text:
(Smith 2023, 245)

Reference:
Smith, John A. 2023. "Climate Change and Human Migration." Journal of 
    Environmental Studies 45 (3): 234-256.
```

### Key Features
- Two distinct systems
- Footnotes allow for explanatory notes
- Most flexible for humanities and sciences

### Best For
History, business, fine arts, and when combining humanistic and scientific sources.

## IEEE Style

Institute of Electrical and Electronics Engineers style uses numbered references.

### In-Text Citation Format
```
Research has shown that neural networks improve accuracy [1].

Smith et al. [1] demonstrated improved accuracy using neural networks.
```

### Reference Format
```
[1] J. A. Smith, "Neural networks for pattern recognition," IEEE Trans. 
    Pattern Anal. Mach. Intell., vol. 45, no. 3, pp. 234-256, Mar. 2023.
```

### Key Features
- Numbered citations in order of appearance
- Compact reference format
- Standard for technical papers

### Best For
Engineering, computer science, and technical fields.

## Harvard Style

Popular in UK, Australia, and some business schools.

### In-Text Citation Format
```
Climate change affects migration patterns (Smith 2023).

Smith (2023) notes that climate change affects migration patterns.
```

### Reference Format
```
Smith, J.A. (2023) 'Climate change and human migration', Journal of 
    Environmental Studies, 45(3), pp. 234-256.
```

### Key Features
- Similar to APA but with formatting differences
- Single quotes around article titles
- 'pp.' for page numbers

### Best For
Business, sciences, and social sciences in UK/Australia/New Zealand.

## How to Choose Your Citation Style

### 1. Check Your Assignment
Most professors or journals specify which style to use. Always follow their guidelines.

### 2. Consider Your Field
If not specified, use the standard for your discipline (see table above).

### 3. Be Consistent
Whatever style you choose, apply it consistently throughout your paper.

### 4. Use Tools
Citation managers like Zotero, Mendeley, or GenPaper can automatically format citations in any style.

## Common Citation Mistakes to Avoid

1. **Mixing styles**: Don't use APA in one paragraph and MLA in another
2. **Missing information**: Include all required elements
3. **Incorrect formatting**: Pay attention to punctuation and italics
4. **Inconsistent formatting**: Same source type = same format
5. **Forgetting page numbers**: Required for direct quotes in most styles
