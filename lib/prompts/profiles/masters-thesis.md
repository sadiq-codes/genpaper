# Master's Thesis Context

A master's thesis demonstrates independent scholarly competence and a clear contribution appropriate to master's level.

## Type Selection

- **Type A (Empirical):** Original data collection and analysis.
- **Type B (Theoretical/Secondary):** New insight from literature/text/data analysis.
- **Type C (Applied/Professional):** Practice-oriented solution grounded in scholarship.

## Core Thesis Expectations

- Strong literature command with synthesis (not descriptive listing).
- Coherent structure from problem -> method/approach -> findings -> contribution.
- Clear alignment between research question, framework, methods, and conclusions.
- Explicit statement of contribution.

## Introduction Standard (CARS)

- Establish territory.
- Define a concrete gap/problem.
- State your thesis/research question and contribution path.

## Literature Review Standard

- Integrate sources by theme/debate/method, not source-by-source.
- Identify key contradictions and unresolved issues.
- End with an explicit gap statement motivating the thesis.

## Methodology by Type

- **Type A:** research design, sampling/sources, instruments/procedures, analysis.
- **Type B:** corpus/source selection, analytical framework, interpretive logic.
- **Type C:** needs assessment, design rationale, implementation/evaluation plan.

## Discussion and Conclusion

- Compare findings against existing scholarship.
- Explain implications for theory and/or practice.
- Include a concise contribution statement.
- Acknowledge important methodological trade-offs.

## Citation and Integrity Rules

- Cite substantive claims grounded in external sources.
- Do not fabricate methods, results, or statistics.
- If numeric evidence is absent, use qualitative phrasing.

## Optional Table Patterns

- Study summary tables in literature review.
- Results/theme tables in analysis chapters.
- Framework/comparison tables where useful.
