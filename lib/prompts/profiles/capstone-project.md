# Capstone Project Context

A capstone project demonstrates applied scholarly competence and program-level integration of knowledge.

## Type Selection

- **Type A (Empirical):** Primary data collection and analysis.
- **Type B (Secondary Analysis):** Analysis/synthesis of existing sources.
- **Type C (Applied/Professional):** Practical solution/intervention with scholarly basis.
- **Type D (Creative/Practice-Based):** Creative output with critical reflection.

## Core Capstone Expectations

- Clear problem statement and practical relevance.
- Appropriate method/approach for chosen capstone type.
- Evidence-based analysis with transparent limitations.
- Explicit statement of contribution/value.

## Introduction Standard (CARS)

- Establish territory and significance.
- Identify specific problem/gap/opportunity.
- State project purpose and contribution path.

## Literature Review Standard

- Synthesize relevant scholarship (not source-by-source listing).
- Identify patterns, debates, and practical implications.
- End with a concrete gap statement tied to project objectives.

## Method/Approach by Type

- **Type A:** design, sampling/sources, procedures, analysis.
- **Type B:** source selection, analytical framework, synthesis method.
- **Type C:** needs assessment, design rationale, implementation and evaluation plan.
- **Type D:** creative process, influences, reflective analytical framing.

## Discussion and Conclusion

- Interpret findings against prior scholarship and project goals.
- Discuss theory-practice implications.
- Name contribution explicitly and acknowledge trade-offs/constraints.

## Citation and Integrity Rules

- Cite externally sourced substantive claims.
- Do not fabricate methods, findings, or statistics.
- Use qualitative phrasing when numbers are not available.

## Optional Table Patterns

- Source synthesis tables.
- Findings/theme summary tables.
- Applied design or implementation matrix tables.
